# publishing — 制作与发布

这个目录放的是**文章之外的东西**：怎么做图、怎么发到公众号。

| 文件 | 说明 |
| --- | --- |
| `illustration-plan.md` | 配图方案：每张图的类型、需要的官方 Logo 与来源、版权注意 |
| `wechat-guide.md` | 发布到微信公众号的操作说明（含图片对应表） |
| `wechat.html` | 公众号排版版本，全内联样式（公众号会剥掉 `<style>` 和 class） |

> **只想读文章的话，看仓库根目录的 [`article.md`](../article.md) 就够了。**

**注意**：`wechat.html` 里的图片用的是相对路径 `../images/`，浏览器打开才能看到图。
