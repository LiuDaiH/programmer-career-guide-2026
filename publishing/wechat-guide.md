# 使用说明

## 文件在哪

```
桌面\
└─ 文章配图\
   ├─ wechat.html        ← 发公众号用这个
   ├─ 公众号版-单文件.html  ← 图片内嵌，传给别人/换电脑看用这个（2.2 MB）
   ├─ 使用说明.md           ← 本文件
   └─ 界面截图\             ← 已抓到的真实界面图（16 张）
```

## 先澄清一个坑：文件传输助手不能用来中转

**症状**：把 HTML 全选复制，粘到「文件传输助手」，结果**排版全没了、图片变成一行文字**（alt 文本）。

**原因**：文件传输助手是**纯文本通道**，只收文字，HTML 样式和图片一律丢弃。**它跟公众号编辑器是两码事** —— 所以拿它测试**测不出公众号的效果**，别被误导。

**正确做法**：**直接粘进公众号的正文编辑区**，不要经过传输助手中转。

**如果确实需要一个带格式的中转**（比如换电脑再发）：用微信的「**收藏**」，它支持富文本；或者直接把 `公众号版-单文件.html` **作为文件发过去**。

## 怎么发到公众号

1. **双击 `wechat.html`**，用浏览器打开（Edge、Chrome 都行）
2. 在页面里 **Ctrl + A 全选**，**Ctrl + C 复制**
3. 打开公众号后台 → 新建图文 → 在**正文区** **Ctrl + V 粘贴**（不要粘到标题栏）
4. 粘完检查两处：**首行标题**（公众号有自己的标题栏，正文里的 h1 可以删掉）和**图片位置**

> 排版（标题样式、引用块、表格）会跟着过去。**但图片不一定能粘过去** —— 见下面第 3 条。

## 两个版本怎么选

| 用途 | 用哪个 | 说明 |
| --- | --- | --- |
| **发公众号** | `wechat.html` | 粘贴后排版会过去；图片可能需要手动补 |
| **发给别人 / 换电脑看 / 存档** | `公众号版-单文件.html` | 图片已内嵌，**单个文件走哪都能正常显示**（2.2 MB） |

**单文件版不要用来发公众号** —— 内嵌的 base64 图片粘不进微信编辑器，发公众号还是用原版。

## ⚠️ 已知的两个坑（2026-09-24 实测）

### 坑 1：`<br>` 换行会被公众号吃掉

**症状**：官网那一段，「TypeScript https://... React https://... Next.js https://...」全挤成一坨。

**原因**：公众号编辑器**不保留 `<br>` 换行**。

**已修**：HTML 里改成**每个网址独立一个 `<p>`**，共 70 行。草稿里那 5 处也已改好并保存（历史版本见 `09-24 23:38 手动保存`）。

### 坑 2：图片粘贴不会带过去

**症状**：正文文字全在，但图片位置只剩图注文字。

**原因**：浏览器复制图片到公众号编辑器**不可靠**，微信限制。

**只能手动补**：点工具栏「图片」→「本地上传」→ 选文件 → 确定。共 8 处，对照下表。

## 注意事项

**公众号正文里的外链不可点击**：微信限制正文中的外部链接（只有「阅读原文」和白名单域名可以跳转）。所以每节的「官网」是**纯文本形式**，作用是让读者**复制粘贴**。这一点没法绕过 —— 除非把域名加白名单。

**链接已验证**：全部 70 个网址逐个访问过，**66 个直连可用**；Hugging Face 官网在国内不可达，已替换为国内镜像 `hf-mirror.com`（实测可用）。发文前建议再点一遍，个别站点偶尔会抽风。

**图片版权**：全部来自各项目官方文档，仅用于技术介绍。文末已加版权声明。如果要用于付费课程或商业培训，建议自己截图替换。

**没抓到的方向**：后端只拿到 Postman（Docker Desktop、Kafka、pgAdmin 的文档站是 JS 渲染的，静态抓取拿不到图）。如果需要 Docker 或数据库客户端的界面图，可以自己在本地跑起来截一张，或者去对应产品的官网找。

**尺寸适配**：抓来的图宽度从 769px 到 2656px 不等，公众号会自动缩放到正文宽度。**Airflow 那两张是 2656×1312，超宽图在手机上会显得很小**，如果介意可以裁掉两侧留白。

## 想要更多界面截图怎么办

同一个抓取脚本可以复用，只要把目标页面换成有截图的文档页即可。有效的页面类型是「**文档站的具体功能页**」（如 `docs/devtools/overview`、`docs/latest/web-ui.html`），官网首页通常只有营销图。
